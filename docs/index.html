What's new in 1.4

A new computer, set up like your old one

Install PolyOS on a new computer, connect your Poly Account, and pick one of your other computers. The new one gets its settings, edition and apps, like cloning a PC. Files stay where they are.

  • Settings: taskbar, pinned apps, wallpaper, theme, clock and power options
  • Edition: Regular, Developer or Gaming, with its apps
  • PolyMarket apps: they install by themselves once the new computer is online
  • A fresh install: PolyOS gets a drive of its own, and setup says exactly what gets replaced

No files or passwords are copied. Each computer's backup (with Poly Sync on) holds only its settings, edition and app list. Every release

Under the hood

Safe, fast, and built on Debian

Debian provides the kernel, drivers, Wi-Fi, audio and apps. PolyOS provides everything you see: plain HTML, CSS and JavaScript in WebKit windows, placed by a Python shell on an Openbox desktop.

  • Firewall on, and Debian's security fixes install by themselves
  • Signed updates: PolyOS refuses an update whose signature doesn't match
  • One small administrator helper, which never keeps your password
  • Tuned for speed: compressed memory, SSD trimming, a lighter mode for older PCs

Questions

Good to know before you install

Is PolyOS free?

Yes. PolyOS is free and open source (GNU GPL v3 or later). There's nothing to buy and no ads.

Will installing erase my computer?

It replaces everything on the drive you choose, including Windows if it's on that drive. Back up your files first, or try PolyOS from the USB drive (nothing changes until you click Install) or in a virtual machine.

Can I keep Windows next to PolyOS?

Yes, with the dual-boot ISO (advanced). Its installer shrinks Windows' partition or uses free space, and a boot menu lets you pick PolyOS or Windows at every start. Back up your files first, and turn off BitLocker / Device encryption and Fast Startup in Windows. The main download is a fresh install on a drive of its own.

Do I need a Poly Account?

No. PolyOS works fully without one and updates itself either way. An account adds sync, device management, account recovery and, new in 1.4, setting up a new computer like one of your others.

How do updates work?

Settings › Updates downloads and installs new versions on your schedule. Every update is signed, and PolyOS refuses one whose signature or checksums don't match.

Will my Wi-Fi, graphics and games work?

Most hardware works out of the box on Debian 13. Driver Manager installs NVIDIA, Broadcom Wi-Fi and other drivers and firmware, and the Gaming edition sets up Steam, Wine and cloud gaming.

Is this the official PolyOS?

PolyOS was created in Scratch by PIXAPoLY Software; this Debian edition is made by Cryptic Software with the team's blessing. It isn't affiliated with the Scratch Foundation, Debian or Microsoft. See the disclaimer.

Where do I get help?

The install guide and documentation cover most things; for anything else, write to us from Help & Support.

While it downloads (a few minutes on a fast connection), choose how you'll use PolyOS:

  1. Write it to a USB driveUse a USB drive of 8 GB or more (everything on it is erased), and balenaEtcher (Windows, Mac, Linux): Flash from file → the PolyOS ISO → your USB drive → Flash. On Windows, Rufus works too (choose DD mode when it asks).
  2. Start from the USB driveRestart with the USB drive plugged in and open the boot menu, usually with F12, F11, F9 or Esc right after turning on. Pick the USB drive. ARM64 computers start it the same way when their firmware is UEFI.
  3. Try it, then installPolyOS starts from the USB drive without changing anything. When you're ready, click Install PolyOS 7 and choose the drive; everything on it is replaced.
  1. PC: VirtualBoxInstall VirtualBox, then New → type Linux, version Debian (64-bit), 4 GB of memory, 2 processors and a 25 GB disk, with the PolyOS ISO as the optical disk.
  2. Apple Silicon Mac: UTMInstall UTM, then Create a New Virtual Machine → Virtualize → Linux → choose the PolyOS ARM64 ISO, 4 GB of memory and a 25 GB disk. Parallels and VMware Fusion work too.
  3. Start itPolyOS starts in the window. Click Install PolyOS 7 to install it onto the virtual disk, then remove the ISO and restart.
