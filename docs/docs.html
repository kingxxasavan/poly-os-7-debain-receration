Install

The install guide covers making the USB drive, starting from it, BitLocker, dual boot next to Windows (or on a D: drive you made), and what to do if something goes wrong.

First start

Setup happens once, on the USB drive, before PolyOS installs. It checks your computer first: the exact model, processor, memory and graphics. Most computers get Everything on; older ones get Smooth or Light, which turn off blur and see-through glass. Then your edition, account, look, Wi-Fi and, if you like, a Poly Account. After the restart you go straight to your desktop; the recommended drivers and your edition’s apps install in the background once you’re online, and a notification says when they’re done.

Settings

  • Display: resolution, refresh rate, orientation, main display, brightness and graphics.
  • Sound: output and input devices, microphone level, and the full mixer for per-app volume and surround.
  • Apps: what starts when you sign in, and uninstall any app with a button.
  • Power & Performance: power modes, the hardware check, Light mode and background activity.
  • Updates: automatic downloads, an install time, restart questions and the update channel.
  • Poly Account: connect, sync, remote management, or stay local.

Updates

PolyOS updates itself from Settings › Updates (and About › Update now), with or without an account. Updates are signed: PolyOS checks every update’s signature and checksums before installing it. You choose whether updates download and install automatically, at what time, and whether PolyOS asks before restarting. Channels: Stable for most people, Beta and Developer for early versions. Some updates are for one edition only (like Vara’s for the Developer edition): PolyOS gets them only if this computer uses that edition or developer mode.

If an update stops with “dpkg returned an error code (1)”, another package on the computer was left half installed. PolyOS 1.2.2 and later repair that and try again by themselves, and name the package if it still fails. On an older version, open Terminal and run sudo dpkg --configure -a then sudo apt-get -f install, and install the update again. Details: /var/log/polyos-update.log.

Without internet, download the newest ISO from the download page and install over the old version.

Drivers

Driver Manager finds NVIDIA and AMD graphics, Wi-Fi (including Broadcom), Bluetooth, touchscreens and pens, webcams and the built-in cameras of newer Intel laptops, and installs what Debian has for them.

Poly Account

A Poly Account is optional. It adds device management, recovery, sync and account emails; PolyOS works fully without one.

  • Connect a computer: during setup, or Settings › Poly Account › Connect. Sign in there, or use the 6-digit code: open the link page on any device and enter it.
  • Each computer has its own key, so removing one (Devices › Remove device) doesn’t affect the others. The computer never keeps your password.
  • Remote management (restart, lock and install updates from the website) is off until you turn it on at that computer.
  • Recovery: a verified email resets your password; so does a recovery key from Poly Account › Recovery.
  • Poly Sync keeps settings, theme, wallpapers and pinned apps the same on your computers. Files aren’t synced.

Vara

Vara is the PolyOS assistant and AI agent. In every edition it opens apps, reads and writes files, writes and runs code, makes 3D models and works with ROS 2 robots and Arduino boards, asking before it changes anything. Choose its provider (Ollama Cloud, OpenAI, NVIDIA or Claude) in Settings › Vara.

With the Developer edition (or developer mode, in Settings › About) Vara also searches the web and drives its own browser, plays music, sets reminders and routines that run on their own, searches your documents, writes itself new tools, and gets the voice, the HUD and an expert helper:

  • Voice: say “Hey Vera”, or give it a name of its own (Settings › Vara › Name; “Jarvis” answers to “Hey Jarvis”). Speech is recognized on your computer. Ask follow-ups without the name; say “stop” to interrupt. Offered when setting up the Developer edition, or install it from Settings › Vara › Voice.
  • Its own browser: a real browser window you can watch, where Vara reads pages, clicks, fills in forms and compares, asking before it acts on a page.
  • Plans: for bigger jobs Vara writes a checklist and ticks it off as it works, checking each step.
  • The HUD: a full-screen interface that opens when it hears its name, or with Win+J.
  • Expert helper: a second model (such as Claude) Vara asks for help with hard code.
